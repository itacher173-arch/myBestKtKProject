# Инфраструктура КТК

## Контур развёртывания (целевой)

| Узел | Назначение | Ресурсы (ориентир) |
|---|---|---|
| АРМ обучаемого | Мнемосхема, управление | 4 vCPU, 8 ГБ ОЗУ, GPU не обязателен |
| АРМ инструктора | Отчёты, аудит, наблюдение | 4 vCPU, 8 ГБ |
| Сервер модели (пром) | Расчёт процесса, сессии | 8+ vCPU, 16–32 ГБ |
| Модуль ИИ (обособленно) | Анализ/прогноз (CPU сейчас; GPU при ML) | Отдельный пул, изоляция сети |
| СХД | Логи, телеметрия, отчёты | Репликация + ежедневный backup |

## Сеть

- Задержка UI↔модель: целевой бюджет **< 100 мс** в LAN (исключение рассинхрона органов управления и приборов).
- Сегментация: VLAN обучения отдельно от АСУ ТП завода (air gap / односторонний шлюз политик).

## Отказоустойчивость

- Резервирование сервера сессий (active/passive).
- Непрерывность: автосохранение журнала каждые N секунд; при обрыве — восстановление сессии по id.
- Прототип: localStorage + пауза сессии на клиенте.

## Мониторинг

- Метрики: число сессий, время отклика, ошибки ИИ-модуля, место на СХД.
- Алерты: недоступность модели, переполнение журнала аудита.

## Прототип сейчас

Одномашинный web/Electron; модель и ИИ in-process; отчёты/аудит в браузере. Целевая схема выше — путь масштабирования без смены UI-контракта.
