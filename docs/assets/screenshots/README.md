# Снимки интерфейса

`trainer-workspace.png` получен из текущего React-прототипа при разрешении 1600×1000. Для документационного запуска использованы синтетический профиль обучаемого и изолированные ответы API; производственные данные, реальные учётные записи и подключения к АСУ ТП отсутствуют.

Снимок обновляется после значимого изменения компоновки рабочего места. Перед коммитом необходимо проверить отсутствие персональных данных, внутренних адресов, токенов и отладочной информации.
