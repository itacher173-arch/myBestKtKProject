# Информационная безопасность КТК

## Данные

- Результаты тренировок, журналы действий, протокол сессии, ФИО/код обучаемого.
- Уровень: внутренние данные обучения персонала (не ПДн специальной категории при использовании табельного кода; при ФИО — режим ПДн).

## Угрозы и меры

| Угроза | Источник | Мера в прототипе | Мера в проме |
|---|---|---|---|
| НСД к отчётам | Обучаемый/гость | PIN инструктора, session auth | AD/RBAC, TLS |
| Подмена логов | Локальный доступ | Отдельный audit log | WORM/подпись, SIEM |
| Подмена результатов | Клиентский storage | Разделение ролей, аудит | Серверная фиксация |
| Утечка сценариев аварий | Копия клиента | Ограничение распространения кейса | Сервер сценариев, DRM/NDA |

## Разграничение

- Обучаемый: только управление в своей сессии (`canControl`).
- Инструктор: отчёты и аудит после PIN; управление процессом недоступно.

## Аудит и реакция на инциденты

- События: вход инструктора, ошибка PIN, старт/пауза/завершение, удаление отчётов.
- Реакция (пром): блокировка учётки, перевыпуск PIN/ключей, разбор SIEM, уведомление ИБ.
