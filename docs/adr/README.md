# Архитектурные решения

ADR фиксируют решения, которые влияют на несколько модулей и не должны теряться в переписке или коде. Статусы: `proposed`, `accepted`, `superseded`, `deprecated`.

| ADR | Решение | Статус |
| --- | --- | --- |
| [0001](0001-ai-is-advisory.md) | AI является отключаемым помощником | accepted |
| [0002](0002-server-authoritative-simulation.md) | сервер владеет состоянием и оценкой | accepted |
| [0003](0003-separate-prototype-and-target-platform.md) | Compose-прототип отделён от целевой платформы | accepted |

Новый ADR содержит контекст, решение, последствия и альтернативы. Изменение принятого решения выполняется новым ADR со ссылкой на заменённый документ.
