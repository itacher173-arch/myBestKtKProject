# ADR-0002: сервер владеет симуляцией и оценкой

- Статус: accepted
- Дата: 2026-08-11

## Контекст

Расчёт процесса и результата в браузере позволяет изменять состояние клиентом, затрудняет совместные сессии и ухудшает воспроизводимость.

## Решение

Авторитетное состояние, тик, отказы, блокировки, версии и журнал действий принадлежат `backend/simulator`. Frontend отправляет команды и отображает проекцию. Сессия фиксирует `seed`, `modelVersion` и `scenarioVersion`.

## Последствия

- критические ограничения проверяются server-side;
- команды и конфликты версий тестируются;
- UI можно развивать без переноса официальной логики оценки;
- совместная работа должна синхронизироваться через серверные события.
