# ADR-0003: прототип отделён от целевой платформы

- Статус: accepted
- Дата: 2026-08-11

## Контекст

Docker Compose удобен для локальной демонстрации, но не реализует требования крупной корпоративной платформы к средам, HA, IdP, ИБ и эксплуатации.

## Решение

Compose сохраняется как воспроизводимый локальный профиль. Kubernetes, WAF/Ingress, OIDC, PostgreSQL HA, очередь, S3, SIEM, Vault и GPU-контур документируются как целевая индустриализация, а не как текущая функция.

## Последствия

- README явно маркирует зрелость решения;
- production-готовность подтверждается только артефактами и приёмкой;
- TEST, PREPROD и PROD имеют отдельные данные и доступы;
- неудачное внедрение требует выполненного и проверенного rollback.
