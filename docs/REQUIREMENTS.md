# БТ / ФТТ / НФТ — КТК ЭЛОУ-АВТ

## Бизнес-требования (БТ)

1. **БТ-1.** Обеспечить безопасную отработку штатных и нештатных сценариев ЭЛОУ-АВТ без воздействия на реальный объект.
2. **БТ-2.** Улучшать навыки оперативного персонала и сокращать время реакции на отказы.
3. **БТ-3.** Оценивать квалификацию обучаемого по эталону и формировать отчёт для инструктора.
4. **БТ-4.** Поддержать каталог сценариев SC-01…SC-15 (отказ оборудования, утилиты, уровни, пуск).
5. **БТ-5.** Использовать ИИ-модуль для разбора ошибок, прогноза риска и адаптивного повтора.

## Нефункциональные требования (НФТ)

| ID | Требование | Реализация / план |
|---|---|---|
| НФТ-1 | Отклик UI < 100 мс на действие оператора | Клиентский React, тик 1 с |
| НФТ-2 | Модульность (схема / модель / сценарии / ИИ / ИБ) | Раздельные модули `src/` |
| НФТ-3 | Переносимость (браузер, Windows portable) | Vite web + Electron |
| НФТ-4 | Разграничение доступа по ролям | `canControl`, PIN инструктора |
| НФТ-5 | Аудит действий ролей | `auditStorage` |
| НФТ-6 | Масштабирование сценариев без переписывания ядра | Каталог `scenarios` / `faultEngine` |

| НФТ-8 | Защита целостности результатов обучения | Аудит + разделение ролей (MVP); серверная подпись — этап промышленного внедрения |
