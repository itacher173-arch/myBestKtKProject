# Экономика и конкурентоспособность (кратко)

## Эффект внедрения КТК

| Статья | Оценка (порядок) | Комментарий |
|---|---|---|
| Снижение простоев из-за ошибок персонала | 0,5–2 ч/инцидент × стоимость часа установки | Отработка редких SC на тренажёре |
| Сокращение срока адаптации новичка | 20–40% | Сценарии + ИИ-повтор вместо только наставничества |
| Снижение риска повреждения оборудования | качественно | Отработка ESD/разгрузки без риска объекту |
| Затраты на КТК (прототип→пром) | лицензия/внедрение + АРМ инструктора | Ниже стоимости часа аварийного простоя |

## Рынок и аналоги

- Зарубежные OTS / operator training simulators (часто закрытый стек, высокая стоимость).
- Российские платформы (напр. линейка DeltaSim и др.) — ориентир по функционалу.
- **Дифференциация решения:** привязка к ЭЛОУ-АВТ и SC-01…SC-15 из регламента; ИИ-разбор с прогнозом риска; лёгкий web/Electron MVP для быстрого пилота.

## Юридические / регуляторные аспекты прототипа

- Используются открытые библиотеки (MIT/Apache и аналоги) — React, Vite и др.
- Кейс и исходные данные — только в рамках чемпионата; промышленное внедрение требует отдельного договора и экспертизы владельца процесса.
- Патентная чистота: архитектура типовая (цифровой двойник + OTS + rule-based coach), без заимствования закрытого кода вендоров.
- Готовность: прототип демонстрационно завершён; промышленный контур — сервер отчётов, AD/LDAP, аттестация ИБ.
