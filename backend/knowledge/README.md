# Модуль базы знаний

Модуль объединяет базовый `seed.json` и тематические пакеты `content/ru` в единый версионируемый каталог. На текущий момент каталог содержит 57 статей в восьми разделах и локальный реестр учебных материалов.

## Структура

- `content/ru` — статьи и long-form дополнения;
- `schema/article.schema.json` — контракт статьи;
- `references/catalog.json` — manifest локальных источников;
- `references/SHA256SUMS` — контроль целостности;
- `assets` — обезличенные SVG-схемы;
- `catalog.py` — загрузка, объединение и поиск;
- `app.py` — HTTP API статей, схем и документов.

В статьях отсутствуют внешние URL. Интерфейс открывает документы по `/api/knowledge/references/{id}`. Полные тексты коммерческих ГОСТ, ISO, IEC и защищённых учебников не размещаются.

Перед изменением прочитайте [`CONTENT_GUIDE.md`](CONTENT_GUIDE.md) и [`references/README.md`](references/README.md). Материал по потенциально опасным действиям требует проверки технологом и специалистом по промышленной безопасности.
