# Локальный фонд источников базы знаний

Документы из этого каталога раздаются только через внутренний API модуля базы знаний.
Статьи не содержат внешних URL: пользователь открывает локальную копию документа из
интерфейса КТК. Каталог `catalog.json` является единственным реестром идентификаторов,
названий, редакций и путей.

В репозиторий включаются только официальные открытые документы и материалы, которые
допускается хранить и распространять в составе учебного прототипа. Полные тексты
коммерческих ГОСТ, API, ISO, IEC и защищённых учебников не копируются. Их обозначения
собраны в `standards-register.md`; действующая редакция проверяется через корпоративную
нормативно-техническую систему перед утверждением статьи.

Добавление или замена файла требует:

1. проверить источник, редакцию и право на локальное хранение;
2. обновить `catalog.json`;
3. проверить открытие файла через `/api/knowledge/references/{id}`;
4. привязать идентификатор к нужной статье или разделу;
5. обновить контрольные суммы в `SHA256SUMS`;
6. провести технологическую и правовую экспертизу перед публикацией.

Файлы, находящиеся в каталоге, включаются в Docker-образ knowledge-service вместе с
приложением. Внешнее сетевое подключение для чтения статьи или документа не требуется.
