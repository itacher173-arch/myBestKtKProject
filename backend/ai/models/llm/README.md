# Локальная LLM

В runtime используется `Qwen2.5-0.5B-Instruct-Q4_K_M.gguf` через
`llama.cpp`. Бинарный файл модели не коммитится: он публикуется как asset
GitHub Release `ai-model-qwen2.5-0.5b-v1` и при первом старте загружается
сервисом `llm-model` в именованный Docker volume.

Источник квантизации:
`bartowski/Qwen2.5-0.5B-Instruct-GGUF`. Исходная модель
`Qwen/Qwen2.5-0.5B-Instruct` распространяется по лицензии Apache-2.0.
Контрольная сумма и точный URL зафиксированы в `manifest.json`.

Для публикации подготовленного локального файла:

```bash
gh auth login
bash scripts/publish-llm-model.sh
```

Модель 0.5B выбрана из-за размера около 379 MiB. Она предназначена для
кратких ответов с RAG-контекстом и не заменяет более крупную LLM для сложного
диалога. Решения о зачёте и рекомендации ML остаются детерминированными.
