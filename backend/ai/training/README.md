# Обучение демонстрационных ML-моделей

Каталог изолирует воспроизводимый контур обучения от runtime-кода AI-сервисов.

```text
training/
├── data/                  # синтетические CSV-наборы
├── generate_dataset.py    # детерминированная генерация с фиксированным seed
└── train_models.py        # обучение, оценка и сохранение артефактов
```

Запуск из корня репозитория:

```bash
python -m backend.ai.training.generate_dataset
python -m backend.ai.training.train_models
```

Результаты записываются в `backend/ai/models`. CSV не содержат персональных или производственных данных и не копируются в runtime Docker-образы. Перед заменой демонстрационных данных реальными необходимы утверждённые правила обезличивания, происхождения данных, разбиения выборок и проверки утечек.
