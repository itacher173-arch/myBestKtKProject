# Движок симуляции

`backend/simulator` владеет авторитетным состоянием учебного процесса. UI не рассчитывает официальный результат и не изменяет состояние напрямую.

| Модуль | Назначение |
| --- | --- |
| `process_model.py` | состояние и дискретный шаг модели |
| `session.py` | сессии, версии, команды и журнал |
| `ticker.py` | серверный такт |
| `faults.py` | воспроизводимая генерация отказов |
| `paz.py` | учебные блокировки и причины отказа команд |

Ключевые требования к изменению:

- одинаковые `seed`, model/scenario version и последовательность команд дают повторяемый результат;
- команда валидируется сервером и фиксируется в журнале;
- критические ограничения не обходятся UI или AI;
- новые параметры имеют единицы измерения, допустимый учебный диапазон и тест;
- значения не выдаются за реальные уставки конкретной установки.

API сессий описан в [`docs/API.md`](../../docs/API.md).
