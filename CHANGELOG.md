# Журнал изменений

Формат основан на Keep a Changelog. Проект использует семантические версии после появления первого формального release; до этого изменения накапливаются в `Unreleased`.

## [Unreleased]

### Added

- единая структура проектной документации;
- эксплуатационный runbook, API-справочник и дорожная карта индустриализации;
- шаблоны issues и pull request;
- политика безопасности, contribution guide и проверка локальных Markdown-ссылок;
- Dependabot-конфигурация для основных экосистем.

### Changed

- корневой и модульные README приведены к фактической структуре проекта;
- CI получает минимальные permissions, concurrency и проверку документации;
- временные сравнения и локальные кэши исключены из Git.

### Security

- демонстрационный `.env.test` с известными паролями удалён; для запуска используется локальный `.env` из безопасного шаблона.

## Правила ведения

- пользовательски значимые изменения добавляются в `Unreleased` в том же PR;
- release переносит записи в секцию версии с датой `YYYY-MM-DD`;
- внутренние refactoring-детали без влияния на пользователей можно не добавлять;
- breaking changes, миграции и security fixes отмечаются явно.
