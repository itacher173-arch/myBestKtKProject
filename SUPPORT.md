# Поддержка

## Куда обращаться

- воспроизводимая ошибка — issue по шаблону `Ошибка`;
- предложение — issue по шаблону `Предложение`;
- вопрос по запуску — сначала [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md);
- уязвимость — только закрытый процесс из [`SECURITY.md`](SECURITY.md).

В обращении указывайте commit SHA, компонент, окружение, шаги, ожидаемый и фактический результат. Логи предварительно обезличиваются.

Поддержка прототипа не включает консультации по управлению реальной установкой, подтверждение производственных уставок или замену локальных эксплуатационных документов.
