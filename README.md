# КТК ЭЛОУ-АВТ

Компьютерный тренажёрный комплекс (кейс Ч2026/ГПН): мнемосхема ЭЛОУ-АВТ, сценарии пуска/останова и отказов, журнал, оценка и разбор действий.

## Запуск

```bash
npm install
npm run dev
```

Обычно: `http://localhost:5173`.

Доступ инструктора: PIN по умолчанию `2026`.

## Возможности

- Мнемосхема ЭЛОУ-АВТ, роли обучаемый / инструктор
- Сценарии: пуск, плановый останов, SC-01…SC-15 / MVP
- Управление: насосы, задвижки, ЭЛОУ, печи, АВО, утилиты
- Журнал, таймер, пауза; чек-лист шагов сценария
- Разбор действий, прогноз риска, рекомендация повторного упражнения
- Отчёты инструктора и журнал аудита
