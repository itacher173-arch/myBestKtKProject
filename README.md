# КТК ЭЛОУ-АВТ — мнемосхема

Web-прототип компьютерного тренажёрного комплекса (кейс Ч2026/ГПН): интерактивная мнемосхема установки ЭЛОУ-АВТ по технологической схеме КТС.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес Vite (обычно `http://localhost:5173`).

## Возможности

- Мнемосхема полной топологии ЭЛОУ-АВТ (схема КТС)
- Роли: обучаемый / инструктор
- Упражнения: штатный пуск + 3 нештатные ситуации
- Управление: насос Н-1, задвижки Л-1/Л-2/Л-3, ЭЛОУ, печи, приборы КИП
- Симуляция параметров (давление, температура, соли, уровни)
- Журнал действий и системных событий, оценка по эталону

## Структура

- `src/scheme/` — каталог оборудования и труб
- `src/sim/` — симуляция, сценарии, контекст тренажёра

## Сборка

```bash
npm run build
npm run preview
```
