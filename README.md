# КТК ЭЛОУ-АВТ — мнемосхема

Web-прототип компьютерного тренажёрного комплекса (кейс Ч2026/ГПН): интерактивная мнемосхема установки ЭЛОУ-АВТ по технологической схеме КТС.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Возможности этапа 1

- Полная топология по зонам: сырьё → подогрев → ЭЛОУ → атмосферный блок (К-1, печи) → К-2 / стриппинги → стабилизация → вторичная перегонка
- SVG-элементы оборудования (колонны, насосы, печи, ТО, ёмкости, ЭЛОУ)
- Основные трубопроводы
- Pan / zoom, выбор элемента, боковая панель сведений

## Структура данных

Каталог оборудования и труб в `src/scheme/` отделён от UI — удобно для будущего переноса доменной модели в WPF.

## Сборка
