# Trainer UI

Главное приложение КТК: дашборд, мнемосхема, сценарии, мини-тренировки, база знаний, AI-чат, отчёты и интерфейс инструктора.

## Команды

```bash
npm ci
npm run dev
npm run build
npm run verify:training
npm run verify:pipe-arrows
```

## Основные каталоги

| Каталог | Назначение |
| --- | --- |
| `src/app` | маршрутизация экранов и роль рабочего места |
| `src/simulator` | клиентская проекция, команды и панели процесса |
| `src/scheme` | топология, оборудование и SVG-мнемосхема |
| `src/scenarios` | каталог упражнений и схема сценария |
| `src/training` | 13 мини-тренировок |
| `src/knowledge` | каталог и просмотр статей |
| `src/ai` | чат и разбор сессии |
| `src/storage` | отчёты обучаемого и инструктора |
| `src/settings` | тема, язык, шрифты и доступность |

Состояние UI не является источником официальной оценки. Все критические команды и доступ к данным проверяются backend.
