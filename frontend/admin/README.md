# Admin UI

Административное приложение для управления пользователями, несколькими ролями, инструкторами, учебными группами и составом групп.

```bash
npm ci
npm run dev
npm run build
```

Каждая операция управления повторно авторизуется backend-ролью `admin` и фиксируется в аудите. Интерфейсное скрытие кнопок не является механизмом безопасности.
