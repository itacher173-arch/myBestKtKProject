# Участие в разработке

Спасибо за вклад в КТК ЭЛОУ-АВТ. Репозиторий объединяет программный код и предметные учебные материалы, поэтому технический review не заменяет технологическую экспертизу.

## Перед началом

- для ошибки сначала проверьте открытые issues;
- для крупного изменения создайте issue с границами и образом результата;
- не публикуйте уязвимости, секреты, персональные данные или внутренние производственные материалы;
- не добавляйте реальные уставки и теги конкретной установки без утверждённого процесса обезличивания.

## Ветки и pull request

```bash
git switch main
git pull --ff-only
git switch -c feat/short-description
```

Один PR решает одну связанную задачу. В описании укажите причину, изменения, способ проверки, риски, миграцию и rollback. Для визуального изменения приложите скриншоты светлой и тёмной темы.

## Обязательные проверки

```bash
ruff check backend --config backend/ruff.toml
python -m compileall backend
pytest -q backend/tests
npm run build --prefix frontend/trainer
npm run build --prefix frontend/auth
npm run build --prefix frontend/admin
python scripts/check_docs.py
```

## Предметный review

| Изменение | Обязательная проверка |
| --- | --- |
| модель процесса, сценарий, параметр | технолог и разработчик симулятора |
| ПАЗ, авария, потенциально опасное действие | технолог и промышленная безопасность |
| статья или источник | методолог, технолог, правообладатель контента |
| роли, сессии, аудит, секреты | информационная безопасность |
| AI/ML/RAG | AI-владелец, методолог, ИБ и regression/eval |
| инфраструктура/миграция | платформа, эксплуатация, DBA и ИБ |

До назначения реальных владельцев `CODEOWNERS` использует владельца репозитория как обязательную точку review.

## Контент базы знаний

Следуйте [`backend/knowledge/CONTENT_GUIDE.md`](backend/knowledge/CONTENT_GUIDE.md). Новая статья должна иметь стабильный `id`, подробный связный текст, локальные источники, границу применимости и связи с оборудованием/сценариями. Изменение статьи безопасности не принимается только по автоматическому тесту.

## AI

AI не может изменять оценку, правила экзамена или состояние симуляции. PR с новой моделью содержит:

- происхождение и лицензию данных;
- model/prompt/index versions;
- фиксированные train/validation/test;
- метрики и сравнение с baseline;
- проверку fallback и полного отключения;
- тесты утечек, prompt injection и неподтверждённых рекомендаций.

## Definition of Done

Код, тесты, документация, переменные окружения и эксплуатационные инструкции согласованы; CI успешен; секреты отсутствуют; breaking changes и rollback описаны; требуемые эксперты подтвердили изменение.
