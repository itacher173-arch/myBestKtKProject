# Frontend КТК ЭЛОУ-АВТ 5.0

React/TypeScript-клиент с интерактивной SVG-мнемосхемой, адаптивной оболочкой, авторизацией, настройками, отчётами, базой знаний и локальным ИИ-помощником.

## Модули

- `src/auth` — авторизация и защищённая сессия;
- `src/layout` — боковая навигация, шапка и контроль сервисов;
- `src/settings` — темы, язык оболочки, шрифты, масштаб и доступность;
- `src/ai` — чат, выводы, отклонения и персональные рекомендации;
- `src/knowledge` — поиск и чтение материалов;
- `src/miniTraining` — точечные уроки;
- `src/sim` — состояние тренажёра, отчёты и взаимодействие с API;
- `src/scheme` — оборудование, трубопроводы и зоны;
- `src/components` — рабочие экраны и панели управления;
- `src/lib` и `src/ui` — API-клиент и общие UI-примитивы.

## Команды

```text
npm.cmd ci --no-audit --no-fund
npm.cmd run build
npm.cmd run dev
```

Vite перенаправляет `/api` на `http://127.0.0.1:8000`. Production-сборку публикует Python Gateway.
