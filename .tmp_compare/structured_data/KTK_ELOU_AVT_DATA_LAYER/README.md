# Структурированный слой данных КТК ЭЛОУ-АВТ

Пакет предназначен для добавления в репозиторий `itacher173-arch/myBestKtKProject`. Он переносит сильную информационную модель второго проекта, но отделяет данные от кода и добавляет явную прослеживаемость.

## Что внутри

- 8 сегментов технологической схемы;
- 138 элементов оборудования и отдельный слой координат;
- 31 параметр модели;
- 17 сценариев;
- 13 мини-тренировок;
- 22 статей базы знаний;
- 12 классов ошибок для ИИ-рекомендаций;
- реестр источников, матрица компетенций и матрица прослеживаемости;
- JSON Schema и автономный валидатор без внешних зависимостей.

## Отличие от текущего проекта

Сейчас часть данных находится в TypeScript и разрозненных JSON сервисов. В пакете предметные данные вынесены в единый версионируемый контур `data/`, а документы и карточки источников — в `docs/`. Это позволяет фронтенду, backend-микросервисам, ИИ и тестам ссылаться на одинаковые идентификаторы.
